# Planifier avant de modifier

Avant la première modification, écris dans ta réponse un plan court :

```
PLAN
- Symptôme : <le test qui échoue et ce qu'il montre>
- Cause supposée : <fichier, fonction, ligne>
- Correctif : <ce que tu vas changer, en une phrase>
- Vérification : <la commande de test, et les cas limites à vérifier>
```

Puis exécute le plan, étape par étape. Si la cause supposée se révèle fausse, réécris le plan avant de continuer.
