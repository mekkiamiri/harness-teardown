# Évals du plugin

Cas lancés par `claude plugin eval ./plugin` (appels de modèle : jamais dans la CI de ce dépôt).
Ils vérifient que le plugin garde son effet quand on le modifie ou quand le modèle change.
Retirer ce dossier ne change rien pendant une exécution : la pièce protège le plugin lui-même.
